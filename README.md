# Verb Pattern Game

A fun and interactive web game designed to help elementary and beginner English learners master verb patterns, specifically focusing on the differences between **to-infinitive** and **-ing** forms. This game is aimed at making learning grammar enjoyable and engaging through dynamic gameplay elements and a modern design.

## Features

* **Interactive Learning**: Engage with different verb pattern challenges such as fill-in-the-blank exercises and drag-and-drop tasks.
* **Modern UI**: A clean, trendy design with animations and smooth transitions that keep the user experience fresh and engaging.
* **Progress Tracking**: Visual indicators such as progress bars and score displays to track learning achievements.
* **Responsive Design**: Optimized for use across devices, from desktop to mobile.
* **Confetti Celebrations**: Celebrate learning milestones with fun, animated confetti after correct answers!

## Technologies Used

* **HTML5**: Structure and content of the web application.
* **CSS3**: Styling and layout, with modern design patterns and animations.
* **JavaScript**: Core interactivity, handling the game logic, and tracking user progress.

## Installation

To get started with the **Verb Pattern Game**, follow these simple steps:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Stefan-29/Verb-Pattern-Game.git
   ```

2. **Navigate to the project directory**:

   ```bash
   cd Verb-Pattern-Game
   ```

3. **Open `index.html`** in your browser to play!

## How to Play

* Select the correct verb pattern (to-infinitive or -ing) for each sentence prompt.
* Drag and drop the correct answer or fill in the blank fields to continue.
* Track your progress with the visual score and progress bar.
* Celebrate your achievements with a fun confetti animation!
